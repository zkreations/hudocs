Esta página es un ejemplo de cómo podría estructurarse la documentación de una versión hipotética 2.0. Las instrucciones mostradas a continuación son únicamente ilustrativas y no representan una instalación real.

## Requisitos

* Hugo 0.164.0 o superior
* Git instalado

## Instalación

En un proyecto real, la versión 2.0 podría añadirse como un submódulo de Git:

```bash
git submodule add https://github.com/example/project themes/example
```
