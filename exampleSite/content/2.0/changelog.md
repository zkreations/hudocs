This page is an example of how a changelog could be structured for a project. The versions and changes listed below are fictional and are provided for demonstration purposes only.

## 2.0.0

**Added**

* Added a new documentation navigation system.
* Added built-in search support.
* Added version indicators to documentation pages.
* Added support for displaying the last updated date.

**Improved**

* Improved page loading performance.
* Improved navigation on mobile devices.
* Improved the documentation layout and typography.

**Fixed**

* Fixed broken links in the sidebar.
* Fixed incorrect active states in the navigation.
* Fixed several issues with responsive layouts.

## 1.1.0

**Added**

* Added support for custom navigation links.
* Added additional configuration options.

**Improved**

* Improved the overall documentation layout.
* Improved accessibility across the site.

## 1.0.0

Initial fictional release used as part of this documentation example.
