Hudocs is designed to build technical documentation and blogs with zero external build tools.

## Key Features

Hudocs provides everything you need to document your projects:

- **Built-in Search:** Client-side search powered by FlexSearch.
- **Multilingual Support:** Seamless translation workflows.
- **Version Switcher:** Multi-version documentation support out of the box.

To get started with Hudocs, check out the [documentation](/docs).
