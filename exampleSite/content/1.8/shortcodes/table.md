title: Tables
description: Responsive tables using markdown syntax.
---

By default in Hudocs 2.0, tables generated with standard markdown syntax are automatically responsive without needing any shortcode wrapper.

## Syntax

```markdown
| Syntax | Description |
| --- | ----------- |
| Header | Title |
| Paragraph | Text |
```
