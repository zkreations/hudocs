Hudocs utiliza el sistema de internacionalización nativo de Hugo para gestionar contenido y textos de interfaz en varios idiomas. Cualquier opción y estructura de contenido multilingüe compatible con Hugo también es compatible con Hudocs.

## Configuración de idiomas

Declara cada idioma dentro del bloque `[languages]` de tu archivo de configuración:

```toml
[languages]
  [languages.en]
    label = "English"
    weight = 1

  [languages.es]
    label = "Español"
    weight = 2
```

* `weight`: determina el orden de los idiomas. El idioma con menor valor se utiliza como idioma predeterminado.
* `label`: nombre que se muestra en el selector de idiomas de la cabecera.

Consulta la [documentación de internacionalización de Hugo](https://gohugo.io/content-management/multilingual/) para conocer las opciones disponibles.

## Traducción de contenidos

### Archivos multilingües

Hudocs utiliza el sistema multilingüe nativo de Hugo para relacionar las traducciones de una página. Por ejemplo, puedes utilizar sufijos de idioma en los nombres de archivo:

```text
content/docs/latest/guides/
├── navigation.md        # Versión en inglés
└── navigation.es.md     # Versión en español
```

Hugo relaciona automáticamente los documentos de una misma página. El selector de idiomas de la cabecera enlaza con la traducción correspondiente cuando está disponible.

### Traducción de índices de sección

Los títulos, descripciones y redirecciones de las secciones también pueden traducirse mediante archivos `_index` específicos por idioma:

```text
content/docs/latest/guides/
├── _index.md        # title: "Guides"
└── _index.es.md     # title: "Guías"
```

## Localización de elementos de interfaz

Los textos fijos del tema, como los marcadores de posición del buscador, los avisos de copiado, las etiquetas de paginación y los nombres de los modos de color, se gestionan mediante archivos TOML en la carpeta `i18n/`.

### Personalizar o añadir idiomas

Para sobrescribir textos existentes o añadir un idioma adicional:

{{< steps >}}

1. ### Crea la carpeta de traducciones

   Crea una carpeta `i18n/` en la raíz de tu proyecto:

   ```text
   mi-proyecto/
   ├── i18n/
   │   └── fr.toml
   └── hugo.toml
   ```

2. ### Añade las traducciones

   Añade las cadenas de traducción en `i18n/fr.toml`:

   ```toml
   [search]
   other = "Rechercher"

   [search_in_doc]
   other = "Rechercher dans la documentation"

   [copy]
   other = "Copier"
   ```

3. ### Registra el idioma

   Registra el idioma en `[languages.fr]` dentro de `hugo.toml`.
{{< /steps >}}

## Búsqueda multilingüe

Hudocs genera un índice de búsqueda independiente para cada idioma configurado. Al realizar una búsqueda desde una versión localizada, los resultados corresponden al idioma seleccionado:

```text
/json/en.docs.latest.index.<hash>.json
/json/es.docs.latest.index.<hash>.json
```
