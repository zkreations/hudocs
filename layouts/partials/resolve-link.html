{{- $href := .href -}} {{- $u := urls.Parse $href -}} {{- $isExternal := or (in (slice "http" "https") (lower $u.Scheme)) (hasPrefix $href "//") -}} {{- $url := cond $isExternal $href ($href | relLangURL) -}} {{- $rel := .rel | default (cond $isExternal "noreferrer noopener" "") -}} {{- $target := cond $isExternal "_blank" "" -}} {{- return (dict "url" $url "isExternal" $isExternal "rel" $rel "target" $target) -}}
